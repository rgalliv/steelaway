## What is deliberately not here

**No AISC tables.** No member weights, section properties, capacities,
tolerances, or bolt values. Those live in the current AISC Steel Construction
Manual and the governing specifications, they are revised, and a stale copy in a
prompt library is a liability rather than a convenience.

Where a prompt needs such a value, it instructs Claude to *name the topic* so you
look it up — never to supply the number from memory. A language model reciting a
tolerance is guessing with confidence, and in this trade that is expensive.
